# 空白作品画廊网站

这是一个可公开分享的作品画廊网站模板，包含例图画廊、价格与活动、联系方式，以及本地可视化后台编辑器。

## 页面

- `/`：例图画廊、价格与活动、联系方式三个场景，可按顶部导航顺序滑动切换。
- `/works`：完整例图画廊。公开页面只显示已经上传的图片，后台仍会显示待上传窗口。
- `/pricing`：兼容入口，会跳转到首页的价格与活动场景。
- `/editor`：后台编辑器预览地址。编辑接口需要本地编辑器服务提供。

后台左侧页面树与用户端导航保持一致：例图画廊、完整例图（画廊展开页）、价格与活动、联系方式。后台只在本地运行，线上只提供已发布的公开内容。

进入后台的“联系方式”页面后，可以在右侧新增、改名、填写或删除 QQ 联系按钮。填写有效 QQ 号后，按钮会显示在公开联系方式区域，用户点击即可打开 QQ 联系入口；未填写的按钮不会显示在公开网页。

## 本地开发

在本目录执行：

```text
npm install
npm run dev
```

默认网站地址是 `http://127.0.0.1:5173/`。需要使用后台时执行 `npm run editor`，或使用套件目录中的后台启动脚本。

## 构建与检查

```text
npm run typecheck
npm run build
npm run verify:build
```

也可以一次执行完整部署检查：

```text
npm run check:deployment
```

构建会生成 `dist/`，并写入 `deployment-info.json`。发布配置会让带文件名的静态资源长期缓存，让 `index.html`、`editor-content.json` 和编辑接口不缓存，避免后台修改后网页继续显示旧内容。

## Vercel 部署

将本目录作为项目根目录导入 Vercel。构建命令使用 `npm run build`，输出目录使用 `dist`。部署后请检查首页、`/works`、`/pricing` 和移动端画廊滚动。

本地编辑器服务用于修改和保存内容；线上公开页面读取发布后的 `public/editor-content.json`。更新图片或文字后重新发布，公开页面即可读取新内容。
